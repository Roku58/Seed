# 11. Seed.AI — キャラAI＋メタAI・自動操縦

採点式（ユーティリティ型）AI。`AiBrain` が全 `IAiConsideration` を採点し、最高得点の
候補が返す `CharacterIntent`（**人間の入力と同じ語彙**）を流す。制御経路はプレイヤーと
完全共通——`InputEmulator` で同じ頭脳がプレイヤーの `ManualLogic` へ入力を注入できる。
メタAI（`AiDirector`）は指示書（`AiOrders`）だけで介入し、ユニットを直接動かさない。

## デモで確認する

- 戦闘の敵は AiBrain 駆動: 追跡（停止距離2.2m）→ 射程2.8m 内かつ**ディレクターの攻撃権が
  下りたときだけ**攻撃
- **メタAIの手心**: プレイヤーの HP が減るほど敵の攻撃間隔が延び（満タン×1／瀕死×2）、
  追い方も緩む——`Sample_BattleDirector` が AiOrders（攻撃許可・攻撃性‰）で調整している
- **[O] = 自動操縦**: プレイヤーが敵と同じ Consideration で勝手に戦い出す。
  HUD も HP も普通に動く＝Controller/Agent/Behavior は手動時と1行も変わらない証拠。
  もう一度 [O] で解除（`ReleaseAll()` で人間の入力へ戻る）

## 最小コード

```csharp
using Seed.AI;
using Seed.Character;
using Seed.Hub.Contracts;

// registry は CharacterRegistry（ICharacterQuery と ICharacterRoster を兼ねる）
// メタAI無し: orders 省略で全許可＝完全自律
var brain = new AiBrain(registry, registry)
    .With(new Sample_ChaseConsideration(FactionId.Players, stopDistance: 2.2f))
    .With(new Sample_AttackConsideration(FactionId.Players, moveId, range: 2.8f));
enemies.Add(new EnemyController(agent, brain)); // Controller が毎 Tick で Think を回す

// メタAIを挟む: AiDirector 派生を第3引数へ。毎フレーム、ユニット Tick より前に director.Tick(dt)
var director = new Sample_BattleDirector(enemyId, playerId, baseInterval: 3f);
var directed = new AiBrain(registry, registry, director).With(...);

// プレイヤーの自動操縦: 同じ brain を InputEmulator で ManualLogic へ注入
var emulator = new InputEmulator(playerController.Manual);
emulator.Drive(brain.Think(in frame)); // 毎フレーム。やめれば次から人間の入力に戻る
```

## 部品の対応表

| 部品 | 役割 |
|---|---|
| AiBrain | ICharacterLogic 実装。採点→最高得点の Act を採用（同点は登録順先勝ち） |
| IAiConsideration | 思考候補1つ。Score（やりたい度・0以下=不参加）と Act（意図を返す） |
| AiBlackboard | ユニット1体の記憶＋AI時計（TimeSeconds）。クールダウンはここで |
| AiDirector / AiOrders | メタAI。攻撃権・攻撃性‰・注目対象の指示書を発行 |
| AttackTokenPool | 同時攻撃数の上限管理（多数敵の「順番に殴る」用） |
| InputEmulator | AI→ManualLogic 注入（自動操縦・デモプレイ・チュートリアル誘導） |

## ハマりどころ

- **Score は読み取りのみ**（世界を変更しない）。記憶への書き込みは Act で行う規約
- 同点先勝ち＝ `.With()` の登録順が優先度を兼ねる
- AiDirector.Tick は**ユニットの Tick より前**に呼ぶ（デモは TickPipeline の Simulation で
  director → characters の順に登録して保証）
- AiOrders は「思考への入力」であり強制ではない（Consideration 側が読んで従う）
- InputEmulator の解除時は必ず `ReleaseAll()`（呼ばないと最後の移動・ガードが入りっぱなし）
- 乱数を使う Consideration には決定的乱数を注入（決定性の維持）

## 増やすとき

- 思考候補 = IAiConsideration 実装1クラス + 構築箇所に `.With(...)` 1行
- 采配ルール = AiDirector 派生（`Sample_BattleDirector` が実例）
